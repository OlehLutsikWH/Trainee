# View Counter

Вставляєте посилання на пости — отримуєте кількість переглядів кожного і загальну суму.

## Що підтримується

| Платформа | Як рахується |
|---|---|
| YouTube (відео, Shorts, live) | Офіційний YouTube Data API, якщо задано `YOUTUBE_API_KEY`, інакше — з публічної сторінки |
| Telegram (публічні канали) | Пост (`t.me/канал/123`) — перегляди цього поста. Канал (`t.me/s/канал` або `t.me/s/канал?before=123`) — кожен із ~20 постів на сторінці окремим рядком. Великі числа Telegram округлює (`1.2K`), тому позначаються «≈» |
| TikTok | З публічної сторінки відео (може блокуватись TikTok) |
| Новинні та інші сайти | Лічильник переглядів зі сторінки статті (schema.org, елемент з класом `views`, або текст «N переглядів»). У десктопній версії, якщо лічильника немає в HTML, 0 або сайт блокує запит (403), сторінка відкривається у схованому вбудованому браузері (до 3 одночасно, до ~15 с на сторінку) |
| Instagram, Facebook, X | Поки ні — перегляди не публічні, потрібне підключення акаунта власника / платний API |

**Вказати на сторінці** (десктопна версія): якщо програма не знайшла лічильник або взяла не те число, натисніть «Вказати на сторінці» й клацніть на число переглядів у вікні сайту. Програма запам'ятає, де лічильник на цьому сайті (файл `site-rules.json` у папці даних програми), одразу перерахує інші посилання з нього, і надалі рахуватиме цей сайт сама.

**Охоплення (оцінка)**: для сайтів, які не показують перегляди, впишіть місячну аудиторію сайту (наприклад, зі Similarweb) у колонці «Охоплення (оцінка)» — один раз на сайт. Програма підставить її в усі публікації з цього сайту, запам'ятає (файл `audience.json`) і покаже окремим підсумком, не змішуючи з реальними переглядами.

Приватні Telegram-канали (`t.me/c/…`) не підтримуються — перегляди бачать лише учасники.

## Перевірка посилань з Excel

1. Виділіть у таблиці колонку з посиланнями (разом з порожніми клітинками) і скопіюйте.
2. Вставте в поле на сторінці — один рядок = один рядок таблиці, порядок зберігається.
3. Після підрахунку натисніть «Копіювати колонку переглядів» і вставте в першу клітинку потрібної колонки Excel.
   Для посилань, де переглядів не знайдено, буде порожня клітинка.

## Програма для Windows (без встановлення Node.js)

Готовий інсталятор збирається автоматично на GitHub (вкладка **Actions** → «View Counter desktop build» → артефакт `View-Counter-Windows`):

- `View-Counter-Setup-*.exe` — звичайне встановлення з ярликом на робочому столі та в меню «Пуск»;
- `View-Counter-Portable-*.exe` — працює без встановлення, можна запускати з флешки.

Програма не підписана цифровим сертифікатом, тому при першому запуску Windows може показати «Windows захистила ваш ПК» → натисніть «Докладніше» → «Виконати все одно».

Щоб опублікувати версію для завантаження за прямим посиланням (сторінка Releases), створіть тег `view-counter-v0.1.0` і запуште його.

Запуск десктопної версії з вихідного коду: `npm install`, потім `npm run desktop`.

## Запуск у браузері (для розробки)

Потрібен Node.js 18+. Залежностей немає.

```bash
cd view-counter
npm start
# відкрийте http://localhost:3000
```

Необов'язково — ключ YouTube Data API (точніше й стабільніше, ніж читання сторінки):

```bash
YOUTUBE_API_KEY=ваш_ключ npm start
```

## API

```bash
curl -X POST http://localhost:3000/api/views \
  -H 'Content-Type: application/json' \
  -d '{"urls": ["https://youtu.be/dQw4w9WgXcQ", "https://t.me/durov/300"]}'
```

Відповідь: `{ "totalViews": 123, "results": [{ "url", "ok", "platform", "title", "views", "error" }] }`
