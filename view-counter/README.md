# View Counter

Вставляєте посилання на пости — отримуєте кількість переглядів кожного і загальну суму.

## Що підтримується

| Платформа | Як рахується |
|---|---|
| YouTube (відео, Shorts, live) | Офіційний YouTube Data API, якщо задано `YOUTUBE_API_KEY`, інакше — з публічної сторінки |
| Telegram (публічні канали) | Пост (`t.me/канал/123`) — перегляди цього поста. Канал (`t.me/s/канал` або `t.me/s/канал?before=123`) — кожен із ~20 постів на сторінці окремим рядком. Великі числа Telegram округлює (`1.2K`), тому позначаються «≈» |
| TikTok | З публічної сторінки відео (може блокуватись TikTok) |
| Новинні та інші сайти | Лічильник переглядів зі сторінки статті (schema.org, елемент з класом `views`, або текст «N переглядів»). Спрацює лише там, де сайт показує лічильник у HTML |
| Instagram, Facebook, X | Поки ні — перегляди не публічні, потрібне підключення акаунта власника / платний API |

Приватні Telegram-канали (`t.me/c/…`) не підтримуються — перегляди бачать лише учасники.

## Перевірка посилань з Excel

1. Виділіть у таблиці колонку з посиланнями (разом з порожніми клітинками) і скопіюйте.
2. Вставте в поле на сторінці — один рядок = один рядок таблиці, порядок зберігається.
3. Після підрахунку натисніть «Копіювати колонку переглядів» і вставте в першу клітинку потрібної колонки Excel.
   Для посилань, де переглядів не знайдено, буде порожня клітинка.

## Запуск

Потрібен Node.js 18+. Залежностей немає.

```bash
cd view-counter
npm start
# відкрийте http://localhost:3000
```

Необов'язково — ключ YouTube Data API (точніше й стабільніше, ніж читання сторінки):

```bash
YOUTUBE_API_KEY=ваш_ключ npm start
```

## API

```bash
curl -X POST http://localhost:3000/api/views \
  -H 'Content-Type: application/json' \
  -d '{"urls": ["https://youtu.be/dQw4w9WgXcQ", "https://t.me/durov/300"]}'
```

Відповідь: `{ "totalViews": 123, "results": [{ "url", "ok", "platform", "title", "views", "error" }] }`
