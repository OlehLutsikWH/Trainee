# View Counter для Google Таблиць

Скрипт для таблиці з публікаціями: вставили посилання — перегляди підтягнулися самі; поруч — колонка «Охоплення (оцінка)»; меню **📊 Перегляди → Оновити дані** оновлює все на сьогодні.

## Встановлення (один раз, ~3 хвилини)

1. Відкрийте таблицю → **Розширення → Apps Script**.
2. Видаліть усе, що є у файлі `Code.gs`, і вставте весь вміст файлу [`ViewCounter.gs`](ViewCounter.gs). Натисніть **💾 Зберегти**.
3. Закрийте вкладку Apps Script і **оновіть сторінку таблиці** (F5) — з'явиться меню **📊 Перегляди**.
4. Перейдіть на аркуш з публікаціями (там, де колонки «URL» і «Перегляди») → **📊 Перегляди → Налаштувати таблицю**.
5. Google попросить дозвіл: **Продовжити → оберіть свій акаунт → Додатково → Перейти до проєкту (небезпечно) → Дозволити**.
   Це стандартне попередження для власних скриптів; скрипт лише читає сторінки за посиланнями й пише в цю таблицю.
6. Готово: праворуч від «Перегляди» з'явилась колонка «Охоплення (оцінка)».

## Як користуватися

- **Нове посилання** вставте в колонку «URL» — перегляди з'являться за кілька секунд.
- **Оновити все на сьогодні:** меню **📊 Перегляди → Оновити дані**. Великі таблиці оновлюються частинами: якщо не встигне за раз, продовжить сама за хвилину.
- **Охоплення:** впишіть місячну аудиторію сайту (150000, 150K, 1.2M) у «Охоплення (оцінка)» **одного** рядка цього сайту — вона з'явиться в усіх його рядках, і в нових теж. Щоб забути аудиторію сайту — очистіть ту клітинку.
- **Ручні значення не чіпаються.** Скрипт оновлює лише клітинки з приміткою «авто…» (наведіть мишку на клітинку, щоб побачити примітку: звідки цифра і коли оновлено). Що ви вписали самі — лишається. Щоб скрипт знову рахував клітинку, очистіть її.
- Чому цифри немає — теж у примітці до клітинки (приватний канал, Cloudflare, лічильника немає тощо).

### Кнопка «Оновити дані» на аркуші (за бажанням)

**Вставлення → Малюнок** → намалюйте прямокутник з текстом «Оновити дані» → **Зберегти й закрити** → клацніть на малюнок → **⋮ → Призначити скрипт** → впишіть `updateAll` → **OK**.

## Обмеження

Сторінки завантажують сервери Google, а не браузер, тому скрипт **не** порахує:
- сайти, що показують лічильник лише після запуску скриптів (напр. УНІАН, NV);
- сайти з перевіркою Cloudflare («Ви людина?»);
- Instagram, Facebook, X, приватні Telegram-канали.

Для них — програма View Counter (вбудований браузер, «Відкрити через Chrome», «Вказати на сторінці») або ручне введення.
